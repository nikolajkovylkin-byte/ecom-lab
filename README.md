# Ecom Lab — продающий сайт

Стек: React 18 + Vite 5 + Tailwind CSS + lucide-react + framer-motion.

## Запуск локально

```bash
npm install
npm run dev
```

Откроется адрес вида `http://localhost:5173`.

## Сборка

```bash
npm run build
npm run preview
```

## Структура

- `src/data.js` — весь текстовый контент, программа, пакеты, FAQ, кейсы (placeholders помечены `[...]`)
- `src/context/PackageContext.jsx` — состояние выбранного пакета, общее для блока пакетов, квиза и формы заявки
- `src/components/` — секции сайта, каждая как отдельный компонент, подключены по порядку в `src/App.jsx`

## Куда уходит заявка (форма подключена по-настоящему)

Форма (`ApplicationForm.jsx`) реально отправляет данные — есть два бесплатных варианта, выбери один:

**Вариант 1 — Telegram-бот (по умолчанию, работает на Vercel из коробки)**

Заявки будут прилетать тебе в Telegram. Настройка:
1. В Telegram у `@BotFather` создать бота командой `/newbot` → получишь токен
2. Написать своему новому боту любое сообщение (иначе он не сможет писать тебе)
3. Открыть `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и найти `"chat":{"id": ...}` — это твой chat_id
4. В проекте на Vercel → Settings → Environment Variables добавить `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`
5. Передеплоить проект

Код функции — `api/submit-application.js`, комментарии там же.

## Отзывы на сайте (с модерацией)

Кнопка «Оставить отзыв» отправляет отзыв **на проверку** — на сайте он не появляется сразу. Ты одобряешь или отклоняешь его на закрытой странице `/admin/reviews`, и только после одобрения он становится виден всем посетителям.

Настройка (один раз, бесплатно):
1. В проекте на Vercel → вкладка **Storage** → **Create Database** → выбрать **KV**, подключить к проекту (переменные окружения добавятся сами)
2. В **Settings → Environment Variables** добавить `ADMIN_TOKEN` — любая длинная случайная строка, это пароль для `/admin/reviews`. Как её придумать: любой набор из 20+ случайных букв и цифр подойдёт, например сгенерированный менеджером паролей
3. Передеплоить проект

Как пользоваться:
- Зайти на `<твой-домен>/admin/reviews`, ввести `ADMIN_TOKEN` — попадёшь в список отзывов «на проверке»
- Нажать «Одобрить» — отзыв в течение секунды появится на сайте в блоке «Отзывы учеников»
- Нажать «Отклонить» — отзыв останется в базе с пометкой «Отклонён», на сайте не появится

Код: `api/reviews.js` (публичная лента — только одобренные + приём новых на проверку), `api/reviews-admin.js` и `api/reviews-moderate.js` (закрытые, требуют `ADMIN_TOKEN` в заголовке) — страница `/admin/reviews` использует их автоматически.

Если также настроены `TELEGRAM_BOT_TOKEN`/`TELEGRAM_CHAT_ID` из раздела выше — при каждом новом отзыве на проверке ты получишь уведомление в Telegram с напоминанием зайти на страницу модерации.

Без подключённого KV кнопка «Оставить отзыв» и страница модерации будут показывать ошибку — сайт при этом не сломается.

**Вариант 2 — Formspree (без Telegram, заявки на email)**

1. Зарегистрироваться на [formspree.io](https://formspree.io), создать форму, скопировать её endpoint (`https://formspree.io/f/xxxxxxx`)
2. Создать файл `.env` (по образцу `.env.example`) и вписать `VITE_FORMSPREE_ENDPOINT=https://formspree.io/f/xxxxxxx`
3. Пересобрать/передеплоить — теперь форма отправляет заявки на почту, привязанную к Formspree

Если ни один из вариантов не настроен, форма покажет ошибку "не получилось отправить" вместо ложного "успешно" — заявки не будут молча теряться.

## Деплой (бесплатно, кроме домена)

1. Залить проект на GitHub
2. Подключить репозиторий к [Vercel](https://vercel.com) или [Netlify](https://netlify.com) (бесплатный тариф) — платформа сама сделает `npm install` и `npm run build`
3. Сайт будет доступен на бесплатном поддомене (`*.vercel.app` / `*.netlify.app`)
4. Купить домен (например, на nic.kz) и привязать его в настройках проекта — единственная платная часть
